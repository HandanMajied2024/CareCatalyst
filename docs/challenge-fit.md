# Challenge fit

AstraZeneca, *Equal Care Across Finland* (Healthcare track).

## Requirements

| Requirement | How we meet it | Status |
|---|---|---|
| Public, aggregate data only, source for every claim | Cited key figures (THL, Syöpärekisteri, Kela) with a source each; region boundaries from Statistics Finland (CC BY 4.0); all patient and regional values in the demo are synthetic | ⬜ |
| ≥ 1 indicator from Goal 3 of the national cancer strategy | **Treatment starts within target times** (THL Ohjaus 21/2016) per county | ⬜ |
| Concrete, actionable proposals | County runs the agent on Maisa; Kela taxi; kotisairaala pilot | ⬜ |
| Working demo (not slides) | Concept A flow + dashboard | ⬜ |

## Judging

| Criterion | Weight | Our answer |
|---|---|---|
| Actionability | 30 % | Named operator (county), existing portal (Maisa), existing services (Kela taxi, kotisairaala) |
| Insight | 25 % | Finds **who** and **why** at **which step**, not just how many |
| Data quality & transparency | 20 % | Source under every number, limits stated |
| Execution | 15 % | Live demo |
| Clarity | 10 % | 2-minute story: problem → today → tomorrow |

## Goal 3 indicators (strategy 2026–2035)

- 5-year survival for poor-prognosis cancers to Nordic level (+14 pp lung, +6 pancreas, +14 liver vs. NORDCAN 2023)
- Cancer mortality −10 % (today 13 300 deaths/year)
- **Patients start treatment within target times** ← our main indicator

## Limits we state openly

- Agent outreach needs county integration per system (Apotti, Lifecare …).
- Consent and GDPR Art. 9/22 constrain risk scoring; B depends on EHDS roll-out.
- Home chemo: Cochrane finds similar cost, safety evidence still uncertain → proposed as a pilot.
